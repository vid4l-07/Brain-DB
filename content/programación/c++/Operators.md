# Incremento y asignación

```cpp
var++;          // Increment var by 1
int i = var;    // Asignar var a otra variable
```

# Operadores aritméticos y compuestos

```cpp
int a = 10, b = 3;
int sum_ab = a + b;
int diff_ab = a - b;
int mul_ab = a * b;
int div_ab = a / b;
int mod_ab = a % b;

a += 2; // a = a + 2
b *= 2; // b = b * 2
```

# Operadores lógicos y de comparación

```cpp
bool result = (a > b) && (b != 0); // Operadores lógicos y de comparación
```

> [!note]
> Los operadores lógicos y de comparación más comunes son: `>`, `<`, `>=`, `<=`, `==`, `!=`, `&&`, `||`, `!`.
